# Season Blog · 星间生活志

使用 Fuwari 主题，部署到 [GitHub Pages](https://seasonzhu.github.io/)。

## 本地预览

使用 Node.js 24 和 pnpm。首次安装后可以运行开发服务器或构建静态站点。

```sh
npx --yes pnpm@9.14.4 install --frozen-lockfile
npx --yes pnpm@9.14.4 dev
npx --yes pnpm@9.14.4 build
```

## 写作

文章位于 `src/content/posts/`，公开地址为 `/blog/<文件名>/`。已发布的文章应保留文件名。推送到 `main` 后，GitHub Actions 构建并发布站点。

[线上写作后台](https://seasonzhu.netlify.app/admin/) 由 Netlify 托管，使用 GitHub 登录。GitHub Pages 的 `/admin/` 会跳转到同一个后台。文章仍写入 GitHub 仓库，经 GitHub Actions 发布。OAuth 密钥保存在 Netlify 项目的安全设置中。

本地开发时，在项目根目录另开一个终端运行 `npx --yes decap-server@3.11.6`，然后打开开发地址下的 `/admin/`。本地代理会把修改写入工作区。

后台可以按栏目分组、按发布日期排序，并在「固定页面」新增、编辑或删除自定义页面。「站点页面」里的关于页只可编辑。正文的「添加组件」菜单提供 B 站视频、剧透折叠和代码块，图片继续使用现有媒体库或外链。

新文章在「工作流」里以草稿保存，准备好后移到「待发布」再点发布。GitHub 后端会在发布前用分支和 Pull Request 保存稿件，公开仓库的草稿仍可能被查看。文章表单里的「草稿」开关专用于在正式站点隐藏已提交的文章。

在「站点页面 → 站点外观」可切换默认配色、上传头像和横幅并预览裁剪。清空横幅字段会随配色使用对应的预设横幅，清空头像字段会恢复默认头像。外观随工作流发布并由 GitHub Actions 部署。

## 编辑器快捷功能

- 正文「添加组件」提供技术文、菜谱、游记、ACG 评论模板，以及提示框和分隔线。
- 文章可在首页置顶。新文章的短链接名可留空，填入时使用小写英文字母、数字和短横线，并保持唯一。已发布文章应保留短链接名。
- 固定页面可以从导航隐藏或调整顺序。隐藏的页面仍可通过直链和固定页面列表访问。
- 「站点页面 → 站点资料」可编辑站名、作者、简介和社交链接。
- 文章编辑器右侧可预览标题、封面和正文排版。
